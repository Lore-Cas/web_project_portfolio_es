# web_project_portfolio_es

## 1. Nombre del proyecto

Tarjeta de presentación digital: portafolio personal Lorena Castán.

## 2. Descripción del proyecto y su funcionalidad

Este proyecto es un portafolio personal creado para presentar mi perfil profesional, habilidades, herramientas y proyectos destacados. La página incluye enlaces de navegación, acceso al perfil de GitHub, demos de proyectos, repositorios y datos de contacto con enlaces a redes sociales.

## 3. Tecnologías y técnicas utilizadas

- HTML5 semántico.
- CSS3.
- Diseño responsive mediante media queries para 1440px, 768px y 320px.
- CSS Grid y Flexbox para la distribución y alineación de los elementos.
- Pseudo-clases `:hover` y `:focus-visible` para estados interactivos y accesibilidad.
- Gradientes CSS para el fondo y los enlaces.
- `@font-face` para utilizar las familias tipográficas Open Sans y Archivo Black proporcionadas por el proyecto.
- Optimización de imágenes mediante formatos WebP, PNG y JPEG.
